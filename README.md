# Клуб «Баланс» — сайт

Многостраничный сайт клуба «Баланс». Первый экран — интерактивный лотос: девять лепестков ведут в девять разделов.

## Что сейчас в репозитории

- `prototype/` — рабочий прототип на чистом HTML/CSS/JS, без сборки:
  - `index.html` — главная: лотос в SVG с псевдо-3D от движения мыши (десктоп), на мобильном — статичный цветок и список разделов;
  - `razdel.html` — образец внутренней страницы с веером лепестков для перехода между разделами;
  - `css/site.css`, `js/lotus.js` — стили и поведение.
- `tools/build_prototype.py` — генератор обеих HTML-страниц (разделы, геометрия лепестков). После правок: `python tools/build_prototype.py`.
- `zastavka-lotos-1_1920.jpg` — исходная заставка, по которой отрисован лотос.

## Как посмотреть

Открыть `prototype/index.html` в браузере или поднять локальный сервер:

```bash
python -m http.server 4173 --directory prototype
```
